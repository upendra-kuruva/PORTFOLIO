Breast Lesion Characterization with CoaT

Computer Vision · Final-year major project

Deep learning with saliency-guided attention for breast lesion characterization. A CoaT Transformer extracts features from mammograms, and ensemble classifiers sort each image into five categories: Benign, Malignant, Normal, Probably Benign, and Suspicious.

NGB
92.33%
HGB
96.0%
XGB
96.92%

Accuracy of each classifier on the same CoaT features (80:20 train-test split). XGBoost performed best, with 97.13% precision, 96.03% recall, and a 96.06% F1-score.

  • Benchmarked NGBoost, HistGradientBoosting, and XGBoost with confusion matrices and ROC curves for each.
  • Added an explainable AI check using Gemini Vision that confirms an uploaded image is a valid mammogram before prediction.
  • Built a Tkinter desktop app with admin login, dataset upload, feature extraction, training, and prediction.
  • Documented in a 100-page project report.
